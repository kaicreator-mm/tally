# Tally v1.4 Source Gap Map

This document maps v1.4 needs to the current source and active Task DAG.

## A0 — Architecture evidence / freeze

### Codex session isolation

**Current source:** `runtimes/codex` intentionally does not declare `session.isolation`.

**Need:** prove per-run isolation without breaking authentication.

**Tasks:** A0-02 → P0-03.

### Assurance default

**Current source:** visible + held-out mechanisms exist, but no v1.4 risk-adjusted L1/L2/L3 policy.

**Need:** fixed-corpus bake-off.

**Task:** A0-03.

### Repair boundary

**Current source:** inner workflow retry exists; outer repair loop does not.

**Need:** freeze nested-loop identity, feedback redaction, cancellation/exhaustion semantics.

**Task:** A0-04.

## P0 — Trust closeout

### ModelProfile propagation

**Current source:** `workflow.runOne` starts Runtime with workspace only.

**Need:** pass requested model profile; preserve requested versus observed identity.

**Task:** P0-01.

### Codex actual runtime identity

**Current source:** `codex.RuntimeSnapshot` knows CLI version/binary/capabilities.

**Need:** carry/persist observed identity generically.

**Task:** P0-02.

### Session isolation implementation

**Task:** P0-03 after A0-02.

### Measurement unknown usage

**Current source:** later reported usage can set `UsageAvailable=true` after a prior missing call.

**Need:** aggregate reported/missing semantics monotonically.

**Relevant P0 closeout task:** use task manifest ownership; do not patch opportunistically.

### Generic inference boundary

**Current source:** `internal/llm`.

**Need:** Domain AI Adapter + thin shared AI Runtime integration.

**Constraint:** do not move AgentRuntime/CodexRuntime.

## P1 — Contract / Policy / Assurance

### Product `Contract`

**Current source:** separate TaskContract + VerificationContract.

**Target:** aggregation/compiler seam first; no broad storage rewrite.

### Policy

**Current source:** `internal/policy` is primarily execution policy.

**Target:** minimal EngineeringPolicy/gate semantics and `requires[]`.

### VerifiedBasis

**Current source:** taskstate already has `Basis` and `Gaps`.

**Target:** extend derived projection with assurance/policy/risk/residual-risk basis rather than creating mutable status authority.

## P2 — Closed loop

### Failure classification

**Target:** typed deterministic routing.

**Task:** P2-03.

### Repair continuation

**Target:** prior immutable candidate → fresh disposable workspace → new run → new candidate → supersession.

**Task:** P2-05.

### RepairPolicy

**Target:** finite outer attempt budget, separate from inner ExecutionPolicy.

**Task:** P2-07.

### Closed-loop orchestrator

**Target:**

```text
Execute
→ Verify
→ Accept
   or
→ Classify
→ Repair / Escalate
→ Verify
```

**Task:** P2-08.

## P3 — MVP Harness / UI

Implement only Bug Fix + Database Migration closed loops and the minimum UI required to launch, inspect and handle Attention.

## P4 — Product validation

Compare same-agent bare path versus Tally closed loop using pre-registered tasks/metrics.

Key metrics:

- Hands-off Completion Rate;
- Time to Accepted Change;
- Human Intervention per Accepted Change;
- 14-day Rework;
- slower escaped-defect/rollback guardrails.

## Rule

Do not fix a gap merely because this document lists it.

The active Task DAG and path ownership decide when and where the change is authorized.
