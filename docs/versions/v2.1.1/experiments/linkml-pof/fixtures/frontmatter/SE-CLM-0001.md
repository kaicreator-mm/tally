# SE-CLM-0001 — SWEBOK v4.0a lists 18 Knowledge Areas

The claim is intentionally scoped to the taxonomy presented by SWEBOK Guide v4.0a. It does not assert that all Software Engineering knowledge is exhausted by these 18 areas or that the areas are mutually exclusive.
