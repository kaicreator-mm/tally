## 1. 从查询合同分离匹配、排序与覆盖

设 D 为所承诺索引版本中合法可搜索且当前有权披露的事实集合，M(q,d) 是业务规定匹配谓词，S(q,d;C) 是基于获权排序语义及统计范围 C 的分数，T(d) 为稳定次键。理想精确 top-k 是对满足 M 的 D 按实际完整比较键排序后取前 min(k,|match|)；要求 C 与 D 同一范围与否由真实排序/非干扰合同决定。候选检索、过滤、排序、截断及披露是不同阶段。不能用低分代表无权，不以访问令牌可读某索引推导其中每条记录可披露，不从返回长度推断匹配总量或实际源完整性。

教学固定分数：U(越权)=100，A(有权)=90，B(有权)=80，C(有权)=70，k=2，所有文档均匹配。合法结果 A,B。先取全域 top2 U,A 再过滤得到 A，漏掉合法 B；预取 top-k+固定常数不能在任意多越权候选时保证补足。能依据完整获权候选排序时再截断；若实现先产生候选，则须证明足够范围或以合法部分/近似结果对外表示。实际披露时仍按当前权限合同核验，不能冻结撤权；查询授权与数据快照分别负责。

## 2. 倒排结构与相关性不是相同事实

明确查询类型：精确 ID、前缀/范围、词项、短语、全文相关性、语义近邻等具有不同匹配含义；相同 find 名称不能抹掉区别。小集合扫描或关系索引足够时不建搜索集群。对于词项检索，倒排表以词项映射到文档身份及实际所需统计/位置；只存文档 ID 可判断本例词项集合的交并，但不能判断短语位置或次数。教学：D1=[red,blue]、D2=[blue,red]、D3=[red,x,blue]，按空格分词、区分位置且无停用词；三者均含 red 和 blue，仅 D1 匹配相邻有序短语 red blue。要答短语必须有位置或重新检查原文；按实际 analyzer、字段、同义词和查询版本解释，不把字符子串等同词项或语义。索引构建、查询规范化若不同也可能漏匹配；配置升级需要评估已索引内容及重建，不从新版查询器推导旧索引已兼容。

Lucene 10.3.1 BM25Similarity 公开文档给出 IDF = ln(1+(N−df+0.5)/(df+0.5))，N 为该统计口径的 docCount，df 为 term docFreq；k1 控制词频饱和，b 控制文档长度归一化程度。教学只考察 IDF：N=10、df=1 的稀有词为 ln(1+9.5/1.5)=ln(22/3)，df=5 的词为 ln(1+5.5/5.5)=ln2，前者更高。此不是完整 BM25 分数，不从词频或 IDF 单项推出最终排序；分数也不是正确概率。若共享统计包含不可披露文档，获权集合不变但 N/df 可能改变：原 N=10,df=1，另加入10条不可见且均含该词，变 N=20,df=11，IDF 变 ln(1+9.5/11.5)=ln(42/23)，下降。这说明统计范围可能影响分数，即使输出已过滤；是否要求不可见文档对获权排序、分数、聚合或时间毫无影响，是额外强非干扰合同。不能从这个教学例断言某实际引擎的权限实现、侧信道可利用性或排序必反转。若业务确需该强合同，应核统计隔离、评分和其它观察渠道，而非仅过滤返回内容。

## 3. 精确 top-k 与有预算候选的不同资格

对有限完整匹配集合 n，完整比较键可全部排序后取 k（比较模型 O(n log n)）；也可单遍维护至多 k 个当前最佳元素的小堆（k≥1，n≥k 时 O(n log(k+1)) 上界，额外 O(k) 元素，忽略读取/评分/最终排序或单列）。证明：处理前 i 个元素后，堆含该前缀的前 min(i,k) 名；新元素若不优于堆中最差且堆满则不可能进入前 k，否则替换最差或加入未满堆，保持不变量；归纳得遍历结束的精确集合，输出仍按完整键排序。若得分并列，明确 ID 等真实次键使全序；k=0 单独按合同返回零个，不宣称无匹配。排序成本不包括索引检索、权限验证、词项读取及评分成本。

当查询只扫描候选 C⊂D，不能因候选内部排序正确称全域精确 top-k：教学 A=90,B=80,C=70,D=95，候选仅 A,B,C，k=2 得 A,B；完整正确为 D,A。若有可证明的未评分候选上界且不可能超越当前第 k 名完整比较键，则可以安全提前停止；只比较分数上界与第 k 名相等仍需核次键。若未证明全域覆盖或安全上界，应按真实接口标记近似、预算耗尽或不完整；不能从近似向量检索无返回推断不存在语义近邻。若业务只求相关候选且容忍漏项，近似检索可减少计算，但需另定义真实评估集、候选覆盖和允许损失；若要求全集导出、严格缺失证明或强权限结果，则必须提供相应完整机制或拒绝不具能力的路径。此处不规定某向量引擎算法或实测召回。

## 4. 分页：唯一排序键与稳定观察集合是两个条件

教学使用已获权且匹配的文档，完整排序键为 (rank asc, id asc)，页面大小2。冻结 S1: A(1),B(2),C(2),D(4)，id 次键 A<B<C<D。第一页 A,B；只使用 rank>2 的下一页得到 D 并漏 C；正确 cursor 在冻结集合中使用严格字典序大于 (2,B)，第二页 C,D。若同排序值既无唯一稳定次键也无适用快照内稳定身份，不能承诺不漏不重。另例：第一页 A,B 之后，插入 X(0)，新集合 X,A,B,C,D，offset=2 返回 B,C 重复 B；删除 A 后集合 B,C,D，offset=2 返回 D 漏 C。游标可避免这两个特定 offset 位移，却不保证跨刷新全集一致：第一页后已返回 A 改 rank=5，游标可再次返回 A；未返回 C 改 rank=0，可永久跳过 C。唯一排序和 seek 本身不冻结集合。

Elasticsearch 8.19 的明确机制：from/size 深分页需各 shard 收集前页及本页命中，受结果窗口限制；search_after 需保持相同 query/sort，以最后 hit 的完整 sort values 继续；刷新可改变结果顺序。PIT 保留索引观察状态，PIT 搜索增加快照内稳定 _shard_doc 次键，后续应使用响应给出的最新 PIT ID；真实有效期、资源保留与关闭按接口合同。PIT 不是业务权限 token、权威 DB 事务或跨多个独立来源的联合一致快照。选固定快照分页须以真正固定的数据与查询/排序版本为基础，服务端 cursor 绑定实际 tenant、当前许可范围/授权版本、规范查询、排序、索引代际/快照、最后排序键及适用期限，防篡改并核当前权利；cursor 含敏感值时需适当保护其可见性。撤权/范围变化若破坏原分页承诺，拒绝旧 cursor 或按新合同重启，不能保持原权限以求稳定。过期快照、shard 故障、索引缺口、取消或超预算按实际结果资格报告，不用空页假装正常结束。

## 5. 选择及可反驳评价（纸面 NOT_RUN）

小型固定列表：完整扫描、全序排序或数据库查询已可满足；若真实高频全文需求才考虑倒排和评分；若明确语义候选允许近似且有实际评估合同才考虑语义检索与候选重排；大结果稳定遍历采用受支持快照与 cursor；只需实时 best effort 浏览则可选择较弱合同并明确重复/变化风险，不能兼作精确导出。分析索引可陈旧但必须注明 generation 与覆盖，不允许用陈旧索引缺失判断权威记录不存在或无权写。权限、统计、召回、输出和持久结果各自独立，不默认建设通用搜索平台。

独立 Oracle：固定合法集合计算 A,B；越权 U 占候选槽的反例；词项交集/短语位置反例；上述 IDF 两种统计变化；候选漏掉 D 的精确/近似区别；同分 rank=2 的 C、两种 offset 漂移与 seek 仍漏/重；固定 S1 的 A,B/C,D，撤权后旧 cursor 不产生新未获权披露；索引版本缺失或部分分片不能报告全集无命中。无实际 Lucene、Elasticsearch、ANN、索引构建、并发、权限或性能执行。实际目标、数据/排序政策由真实 Owner 裁定。
