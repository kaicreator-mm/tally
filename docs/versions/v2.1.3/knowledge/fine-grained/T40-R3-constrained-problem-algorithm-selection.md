# T40-R3 · 多约束问题建模、可行性、目标与算法选型

## 1. 把硬约束、目标、信息与承诺拆开

例如给待处理任务分配满足技能、时间与权限的设备。先核输入集合是否完整、身份/版本、现有不可移动承诺、设备资格、时间及数量单位、资源权威。硬约束决定可行集合 F；目标只在 F 上比较（如最小成本、最大服务数）。如果业务要求全部安排，不能偷偷改成最多安排；如果允许待排队，须明确未安排是否可接受及公平/优先级。优化器输出建议不授予资源占用权。实际提交必须根据当前权威版本、资源状态和权限重新保护联合约束，不能在求解期间锁死未知时长的所有资源作为默认做法。

若多个目标冲突，明确词典序（先最大满足数再最小成本）、获权权重或展示多候选取舍，不能把不同单位随意相加。一个不可接受方案不能因成本更低而获准。未获权成本或缺数据时可先检查可行性/给出条件结果，而非制造精确最优。

## 2. 教学：固定单时段的二部匹配及费用

假定两个任务 A/B，各需一台设备，一个固定时段、同一权威、设备 X/Y 各容量1，允许边由当前资质决定。A 可 X 或 Y，B 只能 X。若按 A 优先选择 X，则 B 无可用设备；实际上 A→Y、B→X 同时可行。因此“首个可用”“先到先得且不给调整”不能保证全批可行。若政策明确到达即不可撤回地承诺且未来任务未知，这是不同在线合同，不以离线最优指责它。若允许修改尚未承诺的候选，可以从 B 经 X 找到已匹配 A 再到空闲 Y，翻转交替路径得到上述匹配；已正式占用的边不由算法随意翻转。

定义二值 x(t,d)∈{0,1}，不合法边固定0；每任务恰一设备（对 d 求和=1），每设备至多一个任务（对 t 求和≤1）。若另有固定资格设备 Z 可用也不能假设所有任务均适用。该模型恰与此单时段独占分配对应：合法分配产生满足约束的二值解；任一满足约束的二值解可逐任务取唯一设备，构成合法分配。给所有任务共用同一台唯一合法设备的输入则不可行，即使设备总数≥任务数。匹配失败需核实际模型及完整资格，不可仅以一轮贪心失败宣称无解。

费用变体：全部四条边均合法，成本 A-X=1,A-Y=2,B-X=2,B-Y=100。两种全量合法分配成本分别101与4；逐任务选择最低成本会得到101，联合最优为4（本例枚举两种）。若 B-Y 为禁止边，即使以100作为“大惩罚”，当其它成本超过100或根本无可行解时仍可能选它；硬约束必须禁止，不以有限费用冒充禁令。若支持部分安排，可加未安排决策并先最大化已安排数，再按获权次目标选择最小费用；例如若仅最小化非负费用且每任务约束改为≤1，空分配成本0会成为合法最优但可能违背服务目标。Google OR-Tools assignment 教学也以二值分配、任务恰一/工作者至多一与总成本描述固定分配；不是本例的实际求解器执行。

## 3. 从问题形状选择候选，不由“复杂”推出通用求解器

| 实际模型形状 | 候选 | 判断及边界 |
|---|---|---|
| 单任务、当前可用资源、独立选择 | 过滤后按获权次序选择 | 无联合竞争时无需全局优化；提交仍核当前 |
| 已给固定时段及占用，问是否可增加一条 | T35-5 的区间/扫描 | 是合法性检查，不是从多个设备选择分配 |
| 同时段、每任务/设备单容量、固定资格 | 二部匹配，或有成本的分配优化 | 单批全量可行性与成本目标不同；重复边、禁止边、固定承诺要表达 |
| 多时段且每任务必须连续使用同一设备、维护窗口/前序 | 显式时间与设备选择、约束求解/整数模型或可证正确的专用算法 | 每槽总容量满足不证明连续同一设备可行；逐槽匹配可能切换设备 |
| 任务持续到达、有限响应时间、已承诺不可改 | 在线选择/重规划尚未承诺部分 | 不假定未来可知；比较实际合同内接受率/稳定性/期限而非虚构离线最优保证 |

时间扩展教学：两槽，X 仅第一槽空闲、Y 仅第二槽空闲，一个任务必须在同一设备连续两槽；每槽均有一台空闲设备却不可分配。若允许任务在槽间迁移且成本/迁移条件满足，则可行，问题合同变了。固定已承诺占用必须作为约束；新计划改动已有承诺需要另有获权动作。通用模型的变量/约束可能随设备×任务×时段增长，预算、解释和模型维护成本须实际评估，不能从算法类别报毫秒。

## 4. 有限计算下的结果资格

将求解结果区分为已找到合法候选（独立核约束）、已证明在明确目标和模型中最优、已证明模型不可行、预算耗尽且尚未证明、模型/输入无效。实际求解器状态须按其版本合同解释，不从超时/未找到解推出不可行，不从一个可行解推出最优。若有可靠下界 L 与可行成本 U，则对最小化问题 L≤最优≤U；只在下界与上界同一模型/单位且有效时使用 U−L 作为绝对差界（相对差需明确分母与零值规则）。实际业务数据陈旧或权限未知，不因数学最优变成有权提交。

教学 Oracle NOT_RUN：独立枚举两个任务的合法注入，分别证贪心失败但可行、101对4、两任务唯一同设备不可行、逐槽充足但连续不可行、空分配反例。模拟初始 X/Y 可用而执行前 X 被占用，最优候选不得越权提交，按合同重算/拒绝。大规模才比较真实工作负载、求解预算、不可行证据、目标差距、维护与重规划代价；此处不执行求解器、性能或产品测试。
