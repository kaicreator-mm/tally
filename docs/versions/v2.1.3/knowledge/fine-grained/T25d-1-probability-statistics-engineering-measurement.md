# T25d-1 · 概率、统计测量与工程证据

#600；K11 经验研究与决策，K10 性能，K05 独立验证。复用 [K11 基础卷二](../../../v2.1.2/software-engineering-knowledge/K11/foundations-deep-dive-02.md) 的反事实与质量底线、[K11 风险](../../../v2.1.2/software-engineering-knowledge/K11/advanced-decision-risk-value-of-information-and-process-cost.md) 的成本与失败样本；本章补概率模型、具体统计量、配对/区组和不确定性推导，不启动新实验。所有数值虚构教学、NOT_RUN。

## 1. 概率、条件与风险

P(A|B)=P(A∩B)/P(B)，前提 P(B)>0。独立时 P(A∩B)=P(A)P(B)，不是任何两失败率都能相乘。例：某服务不可用 A 的概率假定0.1，另一服务不可用 B 概率0.1；若都由同一电源故障引起且事件相同，联合失败0.1而非0.01。冗余架构必须核共享故障域。条件概率的方向不可交换；教学 1000次请求中50次真实故障，告警抓到40故障且95正常也告警，则 P(告警|故障)=40/50=80%，P(故障|告警)=40/135≈29.6%；告警灵敏不代表每次告警都真实故障。数据分布改变时后者也可能改变。频率、模型概率、未知分别记录；0次失败不证明真实风险为0。

期望是按概率加权的随机变量平均，不代表任何单次结果。E(X+Y)=E(X)+E(Y) 不要求独立；Var(X+Y)=Var(X)+Var(Y)+2Cov(X,Y)，只有协方差0时可直接相加。工程资源常共享负载与故障，不能把各阶段不确定性独立组合。不可逆或无权风险不能仅以平均收益抵消（K11 原风险合同）。

## 2. 测量对象、样本和分母

先定义 estimand：例如在指定版本、负载和资源约束下，每个合法任务的正确完成率、端到端耗时或尾延迟，而非“系统更好”。总体与采样框、实验单位与记录单位不同；同一任务重试10次不等于10个独立任务，同一服务器1000个请求可能相关。记录各版本、初态、负载、用户/任务类型、环境、采样/停止规则、失败/未知/未执行及缺失原因。统计口径先定，不能只保留成功请求或为结果改变分母。

| 教学例 | 观察结论及限制 |
|---|---|
| A 8/10，B 6/10 通过 | 差20个百分点；相对 B 为约33.3%（若同口径）；样本小，不证明普遍因果 |
| 100个请求，99个1ms、1个1001ms | 平均11ms，最近秩 p99=1ms，max=1001ms；尾部需更大/代表性样本，定义分位算法 |
| 10个任务，8完成平均2s，2超时10s | 不能报所有任务平均2s；报告完成率、等待上限/删失及结果未知 |
| A/B 每次运行采样100个内部事件，各5次运行 | 内部事件非自动500独立重复；按真实实验单位和层级估计 |

吞吐按时间窗口内实际完成量（与接纳量区别），延迟按同一操作起止与时钟；不同系统时钟不可直接相减，参见 T25b-2。直方图合并需原计数/边界等适用条件，不能平均每台机器的 p99 当总体 p99。样本分布可多峰、长尾；均值不代表典型个体，报告中位数、适当分位、样本量与原始分布。测量设备误差、时钟分辨率、观察开销及统计抽样不确定性是不同因素。

## 3. 配对、区组与因果边界

教学比较两个解析实现的耗时，配对单位为独立数据集/运行环境块，每块 A/B 都执行，顺序随机或平衡，初态重置，目标负载、正确性与超时规则预先冻结。区组控制主要干扰（机器、数据集、负载时段）；随机分配/顺序减少其它混杂，并不消除学习、缓存、共享资源干扰。若同一人或 Agent 先解题后再做同题，第二次已看到答案；需独立会话/可比任务及避免泄漏，无法控制时限制因果声明。对比真实不同任务可使用分层、匹配或随机分配，但不能事后只挑有利配对。重复测量相关时需适当模型或以独立块汇总，不能盲用 iid t 检验。

教学配对差值定义 d=A耗时−B耗时（正为 B 更快）。假定五个独立块 d=[2,0,4,2,2] ms。均值2ms，离均差平方和8，样本方差8/(5−1)=2 ms²，样本标准差√2 ms，标准误√(2/5)≈0.632ms。若差值为独立同分布近似正态且使用预定双侧95% t 区间，df=4 的 t 临界值约2.776，区间为2±1.755≈[0.245,3.755]ms。这是纸面推导，不是实际运行，且 n=5 无法凭样本充分验证正态。95% 频率学置信度指重复抽样方法的长期覆盖率，不是该固定区间中参数的后验概率。区间不含0也不证明所有块更快；若事先要求至少改善3ms，区间未能支持该下限。若区间包含0，不能宣称两实现等效；等效/非劣需预定容忍界及相应设计。显著性不等于实用收益或因果，若质量合同失败，速度比较不得晋升成功。

## 4. 偏差、错误率与有限证据

p 值是在零假设及模型成立下获得至少同样极端统计量的概率，不是零假设为真的概率。I类错误是零假设真时错误拒绝；II类错误是特定备择真时未拒绝，功效=1−β。样本需求依有意义效应、方差、分配、目标错误率而定。多指标、多任务、多次查看后择优报告会扩大误发现风险；预定主要指标、分析及停止规则，探索性结果另标，可按实际问题采用校正或独立确认。若观察独立同分布 Bernoulli 失败且 n 次无失败，P(0失败|p)=(1−p)^n；单侧95%精确上界解 p=1−0.05^(1/n)。n=10 时约0.259，说明10次成功仍不能排除较高失败率；相关样本或不同风险条件不适用此计算。不能把零观察故障当安全证明。

## 5. 工程测量与决策

最低可用报告：固定目标/版本/对照、样本单位和实际分组、记录规则、每组分母和失败/未知、原始统计或可复算摘要、效应量与适当区间、假设限制、实际质量底线和下一步决策。区分观察、因果解释、外部有效性；性能测试应控制预热、缓存、并发负载、GC/IO及测量时间，记录不利结果而非只取最快。成本模型关注实际工作量与等待、资源及维护，不由速度单指标决定。可根据风险和继续测量价值选择停止；不足就保留 NOT_ESTABLISHED，不靠扩大术语掩盖。

Oracle（NOT_RUN）：用上述虚构数据独立复算均值/分位/混淆计数与 t 区间；插入两个超时样本检查不会消失；交换配对顺序并核数据身份；构造共享故障域检查不会错误乘概率；在固定质量失败时速度改善不得报整体收益。
