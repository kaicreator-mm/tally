## 2. 重叠、粒度与导航风险

按同path+blob的包含端点交集重算，4对重叠：RANGE L9–24/G3 L5–44，STAGING L25–44/G3 L5–44，CACHE/G4 同L45–72，EXPORT L62–83/B4 L48–83。原组合与机制阅读目的不同，前3个区间关系中CACHE/G4为唯一完全相同区间，其余为包含；不自动认定同义或删除语义身份。实际同一阅读内容可按冻结path/blob/range共用，若两个用途均有必要则保留两条选择理由与各自Owner；不得因去重截掉范围条件。G3读全段已经含两个机制范围，不要求重复全文注入；G4与CACHE同范围只需实际读一次，按问题判断是否需要组合交接；B4只有审批时不加载长导出。未选区间与独立当前版本适用性仍须核。真正全库近义/语义重复没有穷尽比较；无完全重复有向三元组不证明所有关系有意义。

弱连通分量59/6/2（忽略方向仅用于静态诊断），无孤立引用。6个节点ELICIT/SCENARIO/STYLE/VARIATION/LIFECYCLE/COST、2个BISECT/RESPONSIBILITY独立于其余59；不能靠单根全遍历发现所有知识。无需强造连接以达单图连通，实际决策从问题/Owner/原目录与多入口出发；从导航边找相邻候选时核条件和实际必要性，不将弱连通性、图度数或缺边当证明。关系basis为已有两端引用身份和条件说明，仍是advisory，不是机器可判的充要条件；真实源支持来自先前独审。若实现需要硬前提/Rule，另行获权、绑定可核事实和实际反例；本批不转换。

## 4. 消费合同累计挑战与纸面评估
