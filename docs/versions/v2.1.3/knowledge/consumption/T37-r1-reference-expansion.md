发现入口的 owner 列是从冻结原索引每行第一格的 Kxx 标记提取的 `ownersFromIndex`，含主责与辅助，不是新的权威归属裁定；原文字中存在“跨”与子课程 ID，具体含义仍读原索引和正文。章节顺序按原索引出现顺序，不是优先级、阶段或 DAG；同一章跨多个工程问题时可从不同视图找到。46/46 仅表示已接受细粒度正文在本发现投影中有入口，不意味着整个 K01–K11、165课程点或历史案例全部结构化，更不表示265个独立知识点。章节标题含案例、来源、反例和边界，均只是导航。四分片是同一冻结发现集合，为便于有限读写，不是四个新的知识库或领域。机械生成结果不替代原索引；未来索引/正文变更时读回实际 blob/行，按变化刷新。

T36 与 T37 只读定位投影采用同样的引用约定，不创建第二图谱；各数据集独立给出冻结 corpusCommit，引用键全局不能互相覆盖原ID。消费者设计上先发现，再以实际工程问题读原文核条件，只有已选定的充分范围才可进当前上下文；不能把 JSON 摘要替代原文。已知未命中、未读范围及五个 U 继续保持 UNKNOWN 或按实际需求定向补证，不把全部标题或候选关系一次性注入模型。

## 2. 十一条新增实质判断入口（不依赖受影响的两条P2引用）

| Kxx | 局部键 | 当前材料问题与限定用途 |
|---|---|---|
| K01 | P37-ELICIT | 有权目标/工作/例外不清楚时，选调查方式和交叉核验 |
| K02 | P37-SCENARIO | 根据同一可观察质量场景比较架构 |
| K03 | P37-REPRESENTATION | RI/AF/frame 与别名，检查实际表示和修改范围 |
| K04 | P37-LIFECYCLE | 用真实不确定性和依赖选择活动，不强制逐阶段 |
| K05 | P37-TESTMODEL | 根据缺陷模型、业务范围与独立预期选测试 |
| K06 | P37-BISECT | 历史版本可比时，区分 good/bad/skip 与搜索范围 |
| K07 | P37-RESPONSIBILITY | 实际失败/未知、责任和利益冲突下如实报告 |
| K08 | P37-INSTALLED | 实际制品、支持环境和公开消费者行为 |
| K09 | P37-MIGRATION | 混合版本、回填、真实旧新读写者和合法切换 |
| K10 | P37-RECOVERY | 实际恢复起止、数据一致点及外部未知 |
| K11 | P37-COST | 必要约束满足后的同目标未来成本与敏感性 |

这些引用是选定专业含义的阅读范围，若实际决策需要其它相关机制则继续从原入口发现，不以一条覆盖整个 Kxx。每条的 source/path/blob/range、when/materialFacts/counterexampleOrLimit 均从实际冻结原文核实；具体语义与来源资格不由本投影升级。7条 CONTEXT_FOR 为由两端实际内容支持的条件导航，非硬依赖/自动传递/事实蕴含；关系没有引用 P36-CACHE/P36-EFFECT，也未扩展两者到新的语义实体。

选择完整性独立于发现覆盖。例如用户问题“租户缓存撤权后能否继续输出”可以从标题定位 T35-3 §2，但不能以标题、原索引摘要或未复审P36-CACHE判定当前授权；必须实际阅读保护条件、实际任务合同及交付时序。遇到纯导出不用强制读缓存或 UI。另一问题“邮件发送超时”不自动选Kafka；真实采用Kafka内事务才读具体版本边界。两个整改专门的反例及停止条件在 [修订公开推演](evaluation-and-worked-traces.md) 中；本批不声称已经执行或通过 Oracle。

## 4. 本批验证与下一步

静态验证预期：四个发现分片并集与冻结原入口46路径精确一致、无重复，原 blob、标题/层级与行位置、owner提示与索引行一致。实际生成时逐一取回46个原文并提取265个标题；此为机械定位构建，不是46篇全文专业重审。新增11条引用须独立核每条完整范围支持声明用途、材料事实、正反边界，特别核引用是否遗漏必要前提；7条边方向与条件单独裁定。原 pilot 仅两记录及相关两边发生变化，其他记录和边保持完全一致；旧文件的原 SHA 仍可追溯。静态检查与审核不得将通过提升为模型选择、产品工程或源资格 PASS。

先取得限定独审及两项P2关闭，再扩大受影响语义引用；下一批按实际工程任务和发现的专业组合缺口选更细单元，优先补充 Kxx 之间的可选择机制、相关真实案例和反例定位。并行可做 #563 已有 L1/L2 候选与已接受知识的只读差距核对；不自动启动 #565 修复或生产接入。全库的真实 LLM 检索/应用/维护收益仍未建立，后续真实消费、独立评价和实验必须另行准入。#565 R5 2P1/2P2 OPEN/HOLD；#286 DEFERRED；A24/T4 NOT_RUN/HOLD。无新 CI、Agent、运行、发布、合格 Claim/Case 或实际验证结果。
