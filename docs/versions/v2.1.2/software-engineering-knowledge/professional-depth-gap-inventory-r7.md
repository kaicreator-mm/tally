# R7 软件工程系统知识库：剩余 87 点专业深度差距的源级盘点与分级推进

> [165 点唯一课程台账](foundation-concept-coverage-ledger.md) · [11 模块专业正文地图](systematic-foundation-depth-map.md) · [SWEBOK 18 KA 对照](disciplinary-coverage.md)
>
> **R7 AUTHOR_ANALYTICAL_TRIAGE / NOT_INDEPENDENT_REVIEWED / NOT_SOURCE_QUALIFIED。** 这里的“差距”严格指：在 **R6 已独立接受的 78/165 进阶 A 关联基线**上，其他 87 个课程 ID **没有 A 进阶文章导航**，不是“没有知识/未编写/不正确”。全部 165 ID 原有 S 课程，159 个与 D1/D2 有主题关联、六个另有 R4 Focus；因此不将“无 A”机械升级成 P0/P1 缺陷或教学缺页。

## 1. 优先级判断：缺少链接 ≠ 真正的学科缺陷

从每个知识点的**正确性风险、跨模块推理作用、目前已有 S/D/F 深度、任务使用频率、能否给出区分性反例及真实来源可获得性**决定追加深文。不强制每个知识点一篇重复模板。SWEBOK 的 KA 是学科覆盖地图，不是把所有学科都变成一个 Tally Task Gate。

- **R7_SELECTED (15)**：K01 4、K03 5、K05 6 个课程点。已针对这些点分别撰写需求双向追溯、算法/类型/形式语义、V&V/Oracle 的进阶正文；**尚待 R7 独立审核，不计为已资格通过**。这些优先项有明确的最短错误轨迹与跨层影响。
- **NEXT_HIGH_VALUE (30)**：后续如要改善实际 Agent/DomainHarness 软件工程判断质量，应优先围绕这些点进一步提供原理/反例或真实 Source/Rule 资格；其中已有 Focus 的 K04.F2.3 不因无 A 而要求重写现有专业章节。
- **SCOPE_DRIVEN (42)**：不是低价值或不重要，而是当前已有课程/两卷/Focus 相对足够作为检索入口，需在出现真实任务/来源/反例时再做深度投资；不能将 A 缺失自动判为研究阻塞。

**定量自检**：历史 87 = 本轮选定 15 + 下一优先 30 + 情境驱动 42。R7 的十五点如果得到实际专业深文链接，新 A 仅是 **93/165**，另有 **72/165 无 A**，不等于额外 15 条合格 Source Claim 或完成 93 项独立教材。
