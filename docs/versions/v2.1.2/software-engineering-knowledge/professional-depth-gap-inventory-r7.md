## 1. 优先级判断：缺少链接 ≠ 真正的学科缺陷

从每个知识点的**正确性风险、跨模块推理作用、目前已有 S/D/F 深度、实际任务使用频率（本轮尚无实测）、能否给出区分性反例及真实来源可获得性**决定追加深文。下文优先级是基于合成反例和课程联系的**作者候选排序**，并非根据任何真实 Agent 失败率/任务次数计算出的统计结论。不强制每个知识点一篇重复模板。SWEBOK 的 KA 是学科覆盖地图，不是把所有学科都变成一个 Tally Task Gate。

- **R7_SELECTED (15)**：K01 4、K03 5、K05 6 个课程点。已针对这些点分别撰写需求双向追溯、算法/类型/形式语义、V&V/Oracle 的进阶正文；**已在 R7 旧 Exact SHA 完成独立限定审核（仅文档候选）**。这些优先项有明确的最短错误轨迹与跨层影响。
- **NEXT_HIGH_VALUE (30)**：每行给出独立且可区分的**风险场景 / 未满足原理 / 可能的反例或必要 Owner 证据**，优先级是 Writer 对跨层错误的风险判断而非实测热度排序；没有真实使用频率/严重度量化数据就明确 `FREQUENCY_NOT_MEASURED`。K04.F2.3 已有 Focus，优先的是对真实 Task/审核误判的验证，不是再复制已有专业章节。
- **SCOPE_DRIVEN (42)**：每行记录一个具体的**何时应触发追加研究的条件**，既有课程/两卷/Focus 继续可查；没有触发材料时保持按需，不因缺 A 自动判为研究阻塞。

**定量自检**：历史 87 = 本轮选定 15 + 下一优先 30 + 情境驱动 42。R7 的十五点获得旧 SHA 已审专业正文入口时，R7 基线 A 为 **93/165**，其时尚有 **72/165 无 A**，不等于额外 15 条合格 Source Claim 或完成 93 项独立教材。

## 3. 不能把栏目升级成业务权限或模型成绩

本表的 87 个知识点都属于已有正规课程组织，标签仅用于**内容建设投入排序**。软件工程的定理/方法可以写成原创教学正文，但当它与真实业务/软件版本绑定时，仍需要 Source/Scope/Owner/版本/权利/可观察 Oracle 才能成为正式生产知识。NASA SWE-052 只说明高保证项目双向追溯的重要性；Dafny 只在给定规格和工具执行前提下验证程序；NIST 组合测试也不自动得出某业务规则正确。任何一个引用都不授予 Tally DomainHarness Consumer ABI、Agent/Host 或发布权限。
