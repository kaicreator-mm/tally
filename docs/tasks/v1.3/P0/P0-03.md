## Goal

Introduce one structured executable command value for repro/validation paths: argv, cwd, env, timeout and explicit shell flag.

## Source facts

- internal/runner.Command already uses Argv/Dir/Env.
- Failure/deps paths still persist or execute command strings with strings.Fields.

## PRD references

- §8 structured required gates
- §21.6 Structured Repro
- §32 safety model

## Allowed paths

- `internal/command/spec.go`
- `internal/command/spec_test.go`
- `internal/command/json.go`
- `internal/command/json_test.go`

## Forbidden / ownership boundary

- `All paths not listed in Allowed paths`

Do not redesign adjacent modules. If a required edit is outside Allowed paths, return `BLOCKED` and name the exact path/interface needed.

## Acceptance criteria

1. CommandSpec rejects empty argv when shell=false.
2. Shell semantics are explicit and false by default.
3. JSON round-trip is stable.
4. No process execution is added here.

## Required validation

- `go test ./internal/command/...`

Never claim a validation command passed unless it was actually executed. Environment/tooling absence must be reported as `NOT_RUN(<reason>)`.
