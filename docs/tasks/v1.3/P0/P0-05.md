## Goal

Provide a reusable disposable-worktree lifecycle so execution never mutates an owner primary worktree.

## Source facts

- Latest PRD requires one disposable worktree per CodegenRun and no execution in primary worktree.

1. Creates a worktree at an exact base revision.
2. Cleanup is idempotent after success, failure and cancellation.
3. Refuses to treat the owner primary worktree as disposable.
4. Tests use temporary Git repos and no network.
