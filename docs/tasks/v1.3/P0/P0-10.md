## Goal

Use the new job SQL contract to make Queue recoverable after worker crash without stealing live work.

## Source facts

- Queue currently marks a job running and can leave it there forever.
- Concurrency currently relies only on SKIP LOCKED at initial dequeue.

## Acceptance criteria

1. Claim writes owner and lease.
2. Heartbeat extends only the current owner lease.
3. Expired running jobs are reclaimable.
4. Live leases are never reclaimed.
5. Cancellation does not mark successful completion.
