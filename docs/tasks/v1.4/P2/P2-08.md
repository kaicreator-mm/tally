## Goal

Compose existing TaskExecution and candidate verification services into one bounded closed-loop engine that returns Acceptable or Escalation with VerifiedBasis.

## Source facts

- This is the core missing product loop.

## PRD / architecture references

- PRD §5, §17-18

## Allowed paths

- `internal/closedloop/**`

## Forbidden / ownership boundary

- `cmd/worker/**`
- `web/**`

All paths not explicitly allowed are forbidden unless this task says otherwise. Do not redesign adjacent modules. If a required edit is outside Allowed paths, return `BLOCKED` and name the exact path/interface required.

## Acceptance criteria

1. First-pass PASS terminates without Repair.
2. Repairable FAIL creates next attempt and re-verifies.
3. Non-repairable failures escalate.
4. Cancellation stops current work and produces no fake verdict.
5. All terminal outcomes include basis/reason.

## Required validation

- `go test ./internal/closedloop/...`

Never claim a validation command passed unless it was actually executed. Missing network, dependency cache, credentials, runtime, database, or external AI Runtime access must be reported as `NOT_RUN(<reason>)`.
