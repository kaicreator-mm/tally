# 已验证的服务定义

从 Coolify 等来源抽出来、**并且实际拉起验证过**的服务定义。

```
catalog/
  LICENSE-NOTES.md          ← 没有这个文件不允许开始抽取
  postgres-16/
    definition.yaml
    verified.json           验证时间 + 完整版本组合
```

## 三条规矩

1. **没通过验证的不放这里。** 一条都不放,包括标注"未验证仅供参考"的
2. **只抽实际要用的**,十来个,不要批量抽两百多个。抽了不用的会过期,而过期的定义比没有更糟
3. **`LICENSE-NOTES.md` 是开工前置。** Coolify 的服务定义多为社区贡献的 compose 文件,衍生使用的许可与署名要求要先确认完
